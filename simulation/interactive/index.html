Pipeline Flow

See how an input image is processed through each layer of a deep CNN before reaching the classifier.

Key Concepts

  • Forward Pass: Data flows input → conv blocks → pooling → classifier.
  • Frozen Layers (🔒): Weights are fixed; they preserve ImageNet features.
  • Trainable Layers (🔓): Weights update during fine-tuning.
  • VGG19: 22 Keras layers (16 Conv2D), 20.2M params (base + head).
  • MobileNetV2: 154 layers, 3.0M params (base + head), depthwise blocks.

How to Use

  • Select a Model (VGG19 or MobileNetV2)
  • Adjust the Freeze % slider to control how many layers are frozen
  • Pick a Flower Image and click Start Forward Pass
  • Watch the signal propagate through frozen (gray) and trainable (purple) blocks

Hierarchical Features

CNNs build up increasingly abstract representations layer by layer.

Key Concepts

  • Edge Detection: Early layers detect simple edges and gradients.
  • Texture Patterns: Mid layers recognise repeated motifs (petals, veins).
  • Shape Recognition: Deep layers capture object-level contours.
  • Random Init: Noisy, meaningless activations.
  • Pretrained: General-purpose ImageNet features.
  • Fine-Tuned: Flower-specific, highly discriminative features.

How to Use

  • Choose Model Mode (Random / Pretrained / Fine-Tuned)
  • Select a Flower Image
  • Click Run Extraction and watch the pipeline light up stage-by-stage
  • Compare the Feature Quality bar across modes

Training Dynamics

Explore how hyperparameters shape the training and validation curves.

Key Concepts

  • Freeze %: Higher freeze → less capacity to adapt, but safer.
  • Learning Rate: Controls step size; too high causes instability.
  • Dataset Size: Smaller data increases overfitting risk.
  • Overfitting: Train accuracy ≫ validation accuracy → model memorises.
  • Convergence: Both curves plateau near their best values.

How to Use

  • Choose a Model, then adjust Freeze %, LR, and Data %
  • Click Train to generate animated curves
  • Watch the Overfitting Indicator bar at the bottom
  • Try extreme values (LR=1e-2, Data=10%) to see instability

Embedding Geometry

Visualise how learned representations separate flower classes in 2D space.

Key Concepts

  • Embedding: A vector representation of each image in feature space.
  • Cluster Formation: Similar flowers should group together.
  • Random: Points scattered randomly, no structure.
  • Pretrained: Partial clustering from ImageNet features.

How to Use

Gradient Stability

Understand why careful freezing and low learning rates are crucial during transfer.

Key Concepts

  • Gradient Magnitude: How strongly each layer's weights are updated.
  • Frozen Layers: Zero gradient — no update, knowledge is preserved.
  • Catastrophic Forgetting: Large updates destroy pretrained features.
  • Stability: Low LR + high freeze = safe adaptation.
  • Weight Change: Tracks how much each layer drifts from its pretrained state.

How to Use

  • Adjust Freeze % and LR to see gradient/weight bar charts change
  • Drag Epoch to see gradients evolve over time
  • Watch the Stability Meter and Forgetting Risk indicator
  • Try 0% freeze + high LR to see dangerous instability

Strategy Advisor

Learn when transfer learning helps and when to train from scratch.

Key Concepts

  • Domain Similarity: How similar the source (ImageNet) is to the target.
  • Small + Similar: Freeze most layers, low LR → feature extraction.
  • Large + Similar: Fine-tune more layers for domain adaptation.
  • Small + Dissimilar: Hardest case; reduce capacity to avoid overfitting.
  • Large + Dissimilar: Train from scratch or fine-tune deeply.

How to Use

  • Adjust Domain Similarity, Dataset Size, Freeze Depth, and LR
  • Watch the Strategy Matrix point and Performance Radar respond in real-time
  • Read the Strategy Recommendation panel for advice
